# SportPartner Finder (Система поиска спортивных партнеров)

## Назначение
Сервис предназначен для быстрого и удобного поиска партнеров и единомышленников для совместных спортивных тренировок, пробежек, игр на открытом воздухе и командных видов спорта с учетом геолокации, уровня подготовки и расписания.

## Целевая аудитория
* Спортсмены-любители, ищущие напарников подходящего уровня.
* Новички, которым требуется поддержка и мотивация при начале тренировок.
* Организаторы дворовых и любительских матчей.

## Предметная область
Организация совместных спортивных активностей и нетворкинга в сфере любительского спорта. Предметная область охватывает управление анкетами атлетов, каталогом спортивных дисциплин, тренировочными событиями/заявками и координацией совместных встреч.

## Основные сущности
* **Пользователь (Athlete/User)** — профиль спортсмена с возрастом, городом и уровнем подготовки.
* **Вид спорта (SportType)** — дисциплина (бег, теннис, кроссфит, бадминтон и др.) и специфика инвентаря.
* **Тренировка / Событие (TrainingEvent)** — запланированная тренировка (дата, место, требуемый уровень, число участников).
* **Заявка на матч / участие (MatchRequest)** — запрос на совместную активность и его статус.

## Основные функции
1. Проверка совместимости уровня участников определение, подходит ли уровень напарника для комфортной совместной тренировки.
2. Проверка актуальности даты тренировки валидация даты запланированного события относительно текущего дня.
3. Оценка доступности свободных мест: расчет остатка мест на тренировку и генерация статуса набора участников.

## План развития
На следующих этапах планируется:
* разработка консольного прототипа с коллекциями и циклами (ПР2);
* перевод сущностей на классы и ООП (ПР3);
* разработка веб-приложения на базе фреймворка Django;
* подключение реляционной базы данных (PostgreSQL/SQLite) через Django ORM;
* реализация регистрации, профилей спортсменов и авторизации;
* разработка REST API;
* контейнеризация приложения с использованием Docker;
* настройка CI/CD конвейера.
