# Ответы на контрольные вопросы ПР2

Ответы привязаны к SportPartner Finder. Термины Room и Booking из методички сопоставлены с TrainingEvent и MatchRequest.

## 1. Какие виды коллекций Python вы знаете? Для каких задач предназначен каждый из них?

list — изменяемая последовательность; tuple — неизменяемая; set — уникальные элементы; dict — пары ключ–значение. В ПР2 списки и словари хранят сущности, множество собирает города, кортеж COLLECTIONS задаёт имена коллекций.

## 2. Чем список отличается от кортежа?

Список можно изменять; кортеж не позволяет менять состав. Вложенный изменяемый объект внутри кортежа всё же можно изменить.

## 3. В каких случаях удобно использовать множество?

Множество удобно для уникальных городов и проверки дубликатов. См. statistics и validate_data.

## 4. Почему словари называются коллекцией пар «ключ – значение»?

По ключу получается соответствующее значение, например event['capacity']. Ключ должен быть хешируемым.

## 5. Чем цикл for отличается от цикла while?

for перебирает элементы, while работает, пока условие истинно. service обходит коллекции, cli использует while True для меню.

## 6. Для чего используется функция range()?

range создаёт диапазон целых чисел для перебора, не формируя обычный список заранее.

## 7. Как организовать перебор элементов словаря в цикле?

for key, value in mapping.items(): перебирает пары; keys() — ключи, values() — значения.

## 8. Для чего используются операторы break и continue?

break завершает ближайший цикл, continue пропускает остаток текущей итерации. В find_events continue исключает неподходящие тренировки.

## 9. Как объявить функцию в Python? Что возвращает функция без оператора return?

Функция объявляется def name(parameters):. Если return отсутствует или не содержит выражения, результат равен None.

## 10. Чем позиционные параметры отличаются от именованных?

Позиционные аргументы сопоставляются по порядку, именованные — по имени: join_event(data, 1, 1, today=...).

## 11. Что такое область видимости переменной?

Область видимости определяет доступность имени. Поиск имён обычно идёт по LEGB: локальная, внешняя, глобальная, встроенная. candidate в run_menu — локальное имя.

## 12. Что такое docstring и для чего он нужен?

Docstring — первая строка-документация модуля, класса или функции; доступна через __doc__ и help(). Основные функции проекта документированы.

## 13. Что такое модуль Python?

Модуль — единица Python-кода, обычно файл .py. Например storage.py отвечает за хранение.

## 14. Чем импорт модуля отличается от импорта отдельного объекта из модуля?

import module сохраняет пространство имён модуля; from module import name вводит отдельное имя в текущую область.

## 15. Что такое пакет и для чего нужен файл __init__.py?

Пакет объединяет модули. __init__.py обозначает обычный пакет и может задавать его интерфейс; namespace-пакеты могут существовать без него.

## 16. Для чего используется конструкция try/except?

try содержит потенциально ошибочную операцию, except обрабатывает ожидаемые ошибки. Меню перехватывает ValueError и OSError.

## 17. Чем блок finally отличается от блока else?

else выполняется, если блок try завершился без исключения; finally выполняется при выходе из try независимо от результата и используется для освобождения ресурсов.

## 18. Для чего используется оператор raise?

raise возбуждает исключение. Например join_event отклоняет повторную запись через ValueError.

## 19. Зачем закрывать файл после работы с ним?

Закрытие освобождает файловый дескриптор и завершает работу буферов записи. Нельзя полагаться только на сборщик мусора.

## 20. Какие преимущества дает контекстный менеджер with?

with вызывает протокол контекстного менеджера и закрывает файл даже при ошибке. См. load_data и save_data.

## 21. Что такое интроспекция? Какие функции Python для нее используются?

Интроспекция — исследование объекта во время выполнения: type, isinstance, dir, getattr, hasattr, help. Покажите help(service.join_event).

## 22. Что такое пространство имен?

Пространство имён связывает имена с объектами; у модулей разные пространства имён. Имя main в cli не смешивается с main.py.

## 23. Что такое итератор и генератор?

Итератор выдаёт элементы через __next__ и завершается StopIteration. Генератор — итератор, обычно создаваемый функцией с yield.

## 24. Для чего используется оператор yield?

yield выдаёт значение и приостанавливает функцию до следующего запроса. find_events возвращает подходящие тренировки по одной.

## 25. Что такое лямбда-функция и где она применяется?

Lambda — небольшая функция-выражение. sort_events использует lambda event: event[key] как ключ сортировки.

## 26. Что такое аннотации типов и как они оформляются в сигнатуре функции?

Аннотации описывают ожидаемые типы: def available_slots(data: dict, event_id: int) -> int. Сами по себе не выполняют проверку типов при запуске.

## 27. Для чего используется линтер flake8 и как выполнить проверку кода проекта?

flake8 находит нарушения стиля и некоторые ошибки кода. Запуск из корня: python -m flake8 .; пустой вывод и код 0 означают отсутствие замечаний.

## 28. Какие требования к оформлению кода предъявляются в рамках ПР2?

Осмысленные имена, модули по ответственности, отступы по 4 пробела, разумные строки, отсутствие неиспользуемых импортов, docstring и аннотации основных функций.

## 29. Как устроен автоматизированный тест pytest и что проверяет оператор assert?

Тест — функция test_*. assert проверяет истинность выражения и вызывает AssertionError при нарушении ожидания; pytest.raises проверяет исключения.

## 30. Как запустить тесты проекта и как интерпретировать результат их выполнения?

python -m pytest -q. Для ПР2 результат — 36 passed; failed означает нарушенное ожидание, error — проблему подготовки или выполнения теста.

## 31. Какие функции реализованы в проекте на этапе ПР2?

Реализованы add_athlete, add_event, find_events, sort_events, join_event, cancel_request, statistics, load_data, save_data и функции представления. Три функции ПР1 перенесены в utils.py.

## 32. Как в проекте представлены данные (структуры, формат хранения)?

В памяти — словарь из четырёх списков словарей; на диске — UTF-8 JSON. Ссылки между записями хранятся как ID.

## 33. Как устроена проверка доступности помещения?

В SportPartner аналог помещения — тренировка. Проверяются дата, совместимость уровня, отсутствие активной заявки и capacity минус число активных участников. См. join_event.

## 34. Какие исключения обрабатываются в программе и зачем?

ValueError — неверный ввод, дата, схема данных или бизнес-правило; OSError — файловые ошибки. JSONDecodeError является подклассом ValueError. EOFError и KeyboardInterrupt завершают меню корректно.

## 35. Какие модули входят в состав проекта и как распределена логика между ними?

main — точка входа; cli — ввод/вывод; service — сценарии; utils — общие проверки и ПР1; validation — схема; storage — файлы; tests — проверки.

## 36. Какие конструкции Python применены в реализованных функциях?

Списки, словари, кортежи, множества, for/while, генератор с yield, lambda, with, try/except/finally, функции и аннотации типов.

## 37. Какие части проекта будут изменены после изучения ООП на ПР3?

Словари сущностей заменятся классами; управление местами и статусом перейдёт в методы. Поиск, интерфейс и JSON-схема сохранятся с адаптацией.

## 38. Почему данные проекта хранятся в файлах, а не в переменных программы?

Переменные исчезают при завершении процесса; файл позволяет восстановить состояние при следующем запуске.
